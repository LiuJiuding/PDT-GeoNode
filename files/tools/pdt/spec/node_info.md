# Node Info（按住读节点几何）最小规范

> 决定层。细则与例子在 `../docs/manual/operators/node_info.md`（G7–G13），
> 实测、坑与坐标系推导在 `../docs/09-MMB节点信息.md`。两份都不具有推翻本文件的效力。

## 目标

Houdini 式：按住一个键、光标停在节点上，就看到这个节点流出了什么几何；
节点同时有输入和输出时，看两者的差异。

## 契约

- **触发**：按住快捷键加鼠标中键显示；松开消失。
- **输入**：当前编辑的节点树 + 光标位置。
- **输出**：跟随光标的**只读**信息块。
- **持久化**：无。不改节点、不改几何、不改选择、不写文件。
- **配置**：首选项菜单
## 不变量

- **MMB-1** 只读：不改场景、节点、选择与文件；临时求值产物（临时物体、临时节点组）结束即回收，原对象的显示/隐藏状态复原。
- **MMB-2** 命中判据与 Blender 自身一致：编辑器实际画出的节点矩形（标题带、参数行、空白都算）；重叠取最前；同一批探针点必须与编辑器自己的点击判定逐点相同，UI 缩放不是 100% 时同样成立。
- **MMB-3** 折叠后只剩标题带的节点仍然可读。
- **MMB-4** 帧节点（`NodeFrame`）永远不是命中结果。
- **MMB-5** 信息内容：几何输出的domain和子层（例如mesh下的vertex/edge/face/face corner等）分类的元素计数和属性表（属性名称 + 类型）；节点同时有几何输入与输出时，输出信息中新增的属性名用**单独的颜色**标出（默认 #FFB433，可在首选项里改），多几何输入的节点如join，新增只和第一个输入比；不用加包围盒/坐标哈希信息；信息块的排布参考`./node_info_ui_v3.png`；上方域分类与几何元素数量永远要有（即使数量为0，便于固定显示位置，方便用户比较，只保留domain子类，不需要mesh/curve等大类了），数量的文字比domain子类文字稍大，每个domain子类设置不同的颜色；下方属性几何元素数量为0的就不显示，如果出现网格物体只有曲线的节点多出Mesh Vertex这类空组件，不需要列出属性，blender spreadsheet默认显示的属性如position要有，domain子类颜色要和上方信息颜色保持一致，属性颜色统一；下方属性表按域分组，组顺序与上方一致。
- **MMB-6** 只有几何输入、没有几何输出的节点**默认什么都不显示**（首选项可打开显示输入流）。
- **MMB-7** 手势：按住显示、松开消失；不需要Pin功能；按住拖动时不移动，也不用让信息块消失。
- **MMB-8** 首选项不设置默认快捷键，提醒用户自己到 Keymap 里搜到operator并手改快捷键，提醒文字“Assign one shortcut yourself: Preferences>Keymap>Operator Name”，替换Operator Name为实际名称，不需要其他提示信息；keymap新建未绑定条目、不写 default 表、unregister() 不动用户绑的键；用户可调的设置是1）开关show input-only node，2）滑条Layout/text-size，信息块文字整体缩放，3）每个domain子类的颜色设置，4）属性名称的颜色设置
- **MMB-9** 测试失败可见：键位没到 / 光标不在节点上 / 读几何失败 / 绘制失败四种情况必须能在日志里区分，日志文件无条件写、不受偏好转开关影响。
- **MMB-10** 只报告当前编辑的树；节点组子组内部不在范围内。

## 验收

- 无头：`test_mmb_node_info.py` 全绿。
- 真窗口：`gui_mmb_node_info.py` 全绿，其中"与编辑器自身判定逐点比对"的网格失配必须为 0；含GUI测试**必须**在用户配置下跑,避免用户现场才能发现的bug，例如UI缩放。
- 现场：`qa\mmb\mmb_hit_probe.py` 对自己的工作文件 PASS。

## 明确不做

- 不编辑、不写回任何值（写回是拾取器的职责）。
- 不读子组内部节点。
- 不做 Houdini 那种逐属性 min/max/mean 统计。
- 几何输入与输出都有时**高亮**只到"属性表"，不做逐属性数值统计。
- 信息块不实时跟随光标，只显示在**触发**时候的位置。
- 信息块不做滚动分页。
